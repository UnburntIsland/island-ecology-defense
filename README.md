# island-ecology-defense

島嶼生態保衛戰 — **V37 五階段教學與隨機獎勵版**（2026-10-26）。

## 遊玩

使用 Chrome 或 Edge 開啟根目錄的 [index.html](index.html)。這是完整的單檔遊戲，已內嵌 37 張卡牌插圖、13 張角色立繪，以及 BGM／音效程式，不需要另外下載圖片或安裝套件。

若使用 GitHub Pages，請以根目錄的 `index.html` 作為入口；遊戲也可下載後直接開啟。

## 本次更新（V36 → V37）

- 每回合答對題目後，立即從 16 種獎勵隨機發放一個，移除三選一介面。新增場上單位升星獎勵，沒有可升星單位時補發 2 金幣。
- 新手教學延伸到五階段：守護神小考驗可答錯重試，答對固定讓諸羅樹蛙升為二星；招募第四張水韭並重新部署四星合成卡。
- 維持原商店規則，示範免費從 Lv.1 升到 Lv.2，再刷新解鎖 3 費卡；加入生態廊道購買、施放與場地位置指引。
- 精確安排 15→13→12→9→0 的教學金幣流程，買下並部署野山羊、精準防治及穿山甲。最後教學敵軍提升至六單位與場地卡；透過固定亂數及實際戰鬥規則，完成指定隊伍後獲勝。
- 加入希莉亞告別、玩家立繪表情、庇佑光球與淡出演出，支援鍵盤及減少動態。完成後以全新隊伍進入正式八回合挑戰。
- 保留 V36 的商店／手牌對齊、價格與庫存位置、大字、完整卡面指引、分層圖鑑、音效與卡牌編輯器；卡牌數值及 AI 規則沒有調整。

## 修改卡牌圖片後分享

編輯器的「套用到遊戲」會保存到目前瀏覽器；若要將修改一起交給其他人，請使用「套用並匯出完整遊戲 HTML」，分享下載的 `island_ecology_defense_v37_shared.html`。匯出檔會包含套用後的圖片與卡面設定。
