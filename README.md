# island-ecology-defense

島嶼生態保衛戰 — **V36 商店與手牌齊線版**（2026-10-22）。

## 遊玩

使用 Chrome 或 Edge 開啟根目錄的 [index.html](index.html)。這是完整的單檔遊戲，已內嵌 37 張卡牌插圖、13 張角色立繪，以及 BGM／音效程式，不需要另外下載圖片或安裝套件。

若使用 GitHub Pages，請以根目錄的 `index.html` 作為入口；遊戲也可下載後直接開啟。

## 本次更新（V31 → V36）

- 手牌與雙方編隊移除卡牌上方重複的星級、攻擊、生命；保留名稱與卡面內資訊。
- 商店與手牌移除重複的特殊行動／場地類別文字，讓各類型卡牌的卡面上緣對齊。
- 商店價格移到卡面下方，與庫存並排；統一兩區標題高度與間距，讓商店與手牌的卡面上緣對齊。
- 保留 V31 的完整卡面教學指引、立繪對話與分層物種圖鑑，以及既有遊戲規則、AI、音效與卡牌編輯器。

## 修改卡牌圖片後分享

編輯器的「套用到遊戲」會保存到目前瀏覽器；若要將修改一起交給其他人，請使用「套用並匯出完整遊戲 HTML」，分享下載的 `island_ecology_defense_v36_shared.html`。匯出檔會包含套用後的圖片與卡面設定。
