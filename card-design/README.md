# V44 卡牌與列印輸出

`renderer.js` 與 `card.css` 是共用卡面。正式遊戲顯示即時遊戲資料，列印頁使用已核對過的 `cards-all-data.json`，不把靜態列印數據寫回遊戲。

- `game.js` / `game.css`：商店、手牌、編隊、戰鬥、敵方預覽、圖鑑與查看器的呈現轉接。所有 `island-card`（含合成與支援卡）共用新版正反面。文字型結算列表保留原有資訊，點選開啟同一個查看器。
- `build.mjs`：替換 `index.html` 中 V44 的獨立 style/script 區塊，保留其餘既有程式。字型與授權、故事與卡框內嵌，單檔可離線開啟。
- `print.html` / `export-images.mjs`：63 × 88 mm 比例，420 × 586⅔ CSS px，以 3 倍輸出為 1260 × 1760 PNG。完整插畫使用 contain；長效果增加文字區，插畫等比例縮小。
- `create-word.py`：以工作區文件 runtime 執行。A4 每面最多 9 張，每張獨立浮動圖片，63 × 88 mm。基本卡與升星卡分段，偶數頁背面左右換位供長邊雙面列印。文字已在圖內，Word 可修改位置、大小及替換圖片。
- `verify-word.py`：檢查圖片數量、像素尺寸、Word 圖片尺寸、ZIP 完整性，以及實際 PDF 渲染的紙張與圖片物理尺寸。PDF 僅供內部 QA。
